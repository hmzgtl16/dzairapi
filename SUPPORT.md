# Support

DzairAPI is an independent open source project maintained by one person. Support is provided on a best-effort basis, with no guaranteed response time (see the [Terms of Use](./TERMS.md)).

## Before you ask

1. Check the [README](./README.md) for setup, configuration, endpoints, query parameters and response shapes.
2. Try the API in Swagger UI and check the OpenAPI spec (paths are listed in the README under [API Overview](./README.md#api-overview)).
3. Search the [existing issues](https://github.com/hmzgtl16/dzairapi/issues?q=is%3Aissue) to see whether your question has already been answered.

## Where to get help

| I want to... | Go to |
|---|---|
| Report a bug in the API | [Open a bug report](https://github.com/hmzgtl16/dzairapi/issues/new/choose) |
| Report incorrect or missing division data | [Open a data correction](https://github.com/hmzgtl16/dzairapi/issues/new/choose). A link to the Official Journal text is required |
| Suggest a feature or an API change | [Open a feature request](https://github.com/hmzgtl16/dzairapi/issues/new/choose) |
| Report a security vulnerability | Do **not** open a public issue. Follow [SECURITY.md](./SECURITY.md) |
| Ask about privacy or my data | See [PRIVACY.md](./PRIVACY.md) |
| Report a conduct problem | See [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) |
| Contribute a fix or improvement | Read [CONTRIBUTING.md](./CONTRIBUTING.md) |

## What to include in an issue

- The exact request (for example the `curl` command) and the response, including the status code and the `problem+json` body for errors.
- The API version or release you are using.
- What you expected to happen.
- Logs only if you run the service yourself, with any secrets and personal data removed.

## What is not supported

- Integration help for your own application or framework. The OpenAPI spec and README examples are the reference.
- Custom features or guaranteed uptime for the public service.
- Load or penetration testing against the production API (see [SECURITY.md](./SECURITY.md) and [TERMS.md](./TERMS.md)).

## Supporting Hosting and Maintenance

DzairAPI is free to use and maintained in spare time. These are the ways you can help keep it available and up to date:

- **Use it considerately.** Cache responses on your side, respect the [rate limits](./README.md#rate-limiting), and avoid bulk scraping. Less traffic means lower hosting cost and better availability for everyone.
- **Help with the data.** Verify records against the Official Journal and report mistakes with the data correction template, or send a fix.
- **Help with maintenance.** Bug fixes, tests, documentation and dependency updates are all welcome. See [CONTRIBUTING.md](./CONTRIBUTING.md).
- **Offer hosting or infrastructure.** If your organization can provide hosting, infrastructure credits or monitoring for the public service, open an issue to start the conversation.
- **Spread the word.** Star the repository or mention DzairAPI in your project.

Help with hosting or maintenance doesn't buy priority support, custom features or uptime guarantees. The [Terms of Use](./TERMS.md) apply to everyone equally.
